# Godot 4 project

## Quick start
1. Clone this repository.
2. Open Godot 4.7 and import `stellar-foundry-ui/project.godot`.
3. Run the project with F5.

## Remote repository
- `git@github.com:Jayden-ren/stellar_foundry.git`

## Current scope
- Unified building/resource config in `data/buildings/building_registry.json`
- Autoload registry in `scripts/Autoload/BuildingRegistry.gd`
- Runtime state in `scripts/Autoload/GameData.gd`
